apkverifier — certificate extractor (browser)

This is the browser counterpart of scripts/extract-cert.cjs. It calls the very same verifyApk you’d invoke from Node, but reads the APK through the Web platform instead of node:fs / process.argv.

⚠️ The library build is compiled as native ESM into dist-browser/. Before opening this page run npm run build:browser once.
No build? Use the commented-out esm.sh import below instead.
